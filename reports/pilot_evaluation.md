# 의료 정책 카드 파일럿 비교 절차

## 범위와 입력

`config/pilot.yaml`의 5개 동(구룡포읍·장기면·호미곶면·대송면·동해면)을 평가한다. 이 동 안의 의료시설은 현재 37건이다. 접근성 점수는 경계 밖 시설의 영향을 유지하도록 포항 전체 908건과 29개 동을 사용한다. 현재 평가 범위는 정책 처방의 유용성에 관한 것이며, 격차 점수의 현장 정확도를 검증했다는 뜻은 아니다.

`scripts/build_pilot_review.py`는 각 동의 같은 점수·인구·격차 유형·조사 근거를 제시하고, 기존 LLM 카드와 고정 규칙 카드의 표시 순서를 섞는다. 규칙 카드는 `rule_card()`의 조건문으로 결정된다. 기존 LLM 카드는 이미 생성된 `data/processed/policy_cards.parquet`를 사용하므로 API를 다시 호출하지 않는다. 카드 A/B의 출처는 Git에서 제외되는 `data/interim/pilot_review_answer_key.csv`에만 저장한다. 평가자에게 저장소 전체를 공유하면 키가 노출될 수 있으므로 `review_form.csv`만 전달한다.

## 진행

1. 평가 담당자에게 `review_form.csv`만 전달한다. 로컬 정답 키는 평가가 끝날 때까지 별도로 보관하고 공유하지 않는다.
2. 각 카드의 세 항목을 1~5점으로 채우고, A/B/동률 중 하나를 선택한다. 의심스러운 수치·행정동 사실·법적 실행 조건은 마지막 열에 구체적으로 적는다.
3. 점수를 고정한 뒤 정답 키를 열어 카드별 평균과 각 동의 차이를 계산한다. 평가자 이름과 날짜, 원본 평가표 위치를 `reports/collaboration_evidence.md`에 기록한다.

| 항목 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 근거 일치 | 수치·지역 범위가 근거와 충돌 | 큰 충돌은 없으나 출처·범위가 모호 | 수치·조사 범위·행정동 사실이 정확히 구분됨 |
| 지역 적합 | 다른 동에도 그대로 붙일 수 있음 | 동의 성격·수요 중 하나만 반영 | 동의 성격·수요·접근성 특징에 맞춘 선택이 드러남 |
| 실행 가능 | 권한·법규·자원 면에서 실현 곤란 | 담당 기관·절차 확인이 필요 | 담당 기관과 첫 실행 단계를 현실적으로 제시 |

5개 사례의 결과는 탐색적 비교다. 평균 차이가 작거나 일관되지 않으면 LLM의 우월성을 주장하지 않고 “정책 초안 작성 보조”로 범위를 낮춘다. 실제 평가와 외부 지표 대조는 아직 수행되지 않았다.

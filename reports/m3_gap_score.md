# M3 — 격차 점수(Gap Score) 프로토타입

작성일: 2026-09-16
근거: README §5 인터페이스 계약(`gap_scores.parquet [adm_cd, fac_type, gap_score, rank, cluster_id]`), §7 방법론 노트, `reports/m2_two_sfca.md`(임계거리 순위 불안정성)

## 공식

`src/gap/score.py`의 `compute_gap_scores()`:

```
gap_score = w_demand × norm(수요) + w_access × (1 − norm(접근성))
```

- **수요(demand)** = `pop_foreign / pop_total` (외국인 인구 **비율**, 절대값이 아님). 절대값을 쓰면 인구 규모가 큰 행정동(오천읍 등)이 외국인 비율과 무관하게 자동으로 수요 상위가 되어, "이 동네에서 외국인 주민이 상대적으로 얼마나 큰 비중인가"라는 격차 진단의 원래 질문과 어긋난다.
- **접근성(access)** = `accessibility.parquet`의 `access_index`(M2, 바닐라 2SFCA, 기본 임계값 3km). `1 − norm(access)`로 뒤집어 "접근성 결핍" 방향으로 맞춘다.
- 두 성분 모두 도메인(`fac_type`)별로 따로 min-max 정규화한다. 현재는 "보건의료" 도메인 하나뿐이라 실질적 영향은 없지만, 향후 "금융" 도메인이 다시 붙었을 때 서로 다른 척도의 `access_index`를 하나로 섞지 않기 위한 설계다.
- `rank`는 `gap_score` 내림차순(1위 = 격차 최대 = 우선순위 최고).

## 가중치 — 0.5/0.5 중립 기본값

`config/weights.yaml`의 `demand_weight`/`access_weight`는 각 0.5다. 이는 수요·접근성을 동등하게 놓은 비교용 중립 기본값이다. GM 담당자의 실제 판단·확정 기록은 `reports/collaboration_evidence.md`에 아직 첨부되지 않았다. 상위 4개 동(구룡포읍·호미곶면·장기면·대송면)이 임계거리 변화에 상관없이 최우선 구간에 남는지는 아래에서 확인했다. 가중치는 2026-10-09 `reports/m6_validation.md`에서 따로 비교했다: 수요 가중치 0.4 이상이면 임계거리 1/3/5km 어디서든 4곳이 5위 안에 남고, 접근성에 70% 이상 무게를 두면(수요 0.3 이하) 일부가 밀려난다. 즉 "가중치와 무관하다"가 아니라 "수요를 어느 정도 이상 반영하는 한 안정적"이다.

`load_weights()`는 두 가중치의 합이 1.0이 아니면 바로 에러를 낸다 — 편집 중 오타가 조용히 결과에 반영되는 것을 막기 위해서다.

## cluster_id는 사분위 구간이지 클러스터링이 아니다

README 인터페이스 계약(`gap_scores.parquet`)에 `cluster_id` 필드가 있고 `src/gap/cluster.py`가 "정책 유형 분류"를 맡을 예정이지만, 이번 M3에서는 별도 클러스터링 모듈을 만들지 않았다. 이유: 현재 특징(feature)이 `gap_score` 하나뿐이다(M4 NLP 수요 신호가 아직 없음). 단변량 특징에 KMeans 등을 돌려도 결과는 정렬 후 구간을 나누는 것과 동일하다 — 라이브러리를 쓰는 것이 "가짜 정교함"이 될 뿐이다. 그래서 `score.py` 안에 `_assign_priority_tier()`로 순위 기반 4분위(1=최우선~4=양호)만 매겼다. `cluster_id`는 "우선순위 구간"일 뿐 정책 유형이 아니다 — 보고서·대시보드에서도 그렇게 부른다. M4(MDIS)는 포기했으므로(`reports/m4_nlp_substitute.md`) 행정동별 결핍 유형 축은 생기지 않는다. 대신 이미 있는 두 축(수요 정규화값·접근성 정규화값)을 중앙값으로 나눈 **격차 유형 4종**을 아래 "임계거리 통합 순위와 격차 유형" 절에서 따로 만들었다.

## 임계거리 민감도 — access_index보다 gap_score 상위권이 더 안정적이다

`m2_two_sfca.md`는 "임계거리(1/3/5km)를 뭘 고르냐에 따라 29개 행정동 전부 순위가 최소 한 번은 바뀐다"고 경고했다. `gap_score_sensitivity()`로 같은 검증을 격차 점수까지 이어서 확인했다.

| | 순위가 한 번이라도 바뀐 동 수 (29개 중) |
|---|---|
| access_index만 (m2) | 29 |
| gap_score (수요+접근성 결합) | 25 |

개별 순위 변동은 여전히 크지만(평균 변동폭 4.6), **최우선 구간(top 5)은 임계거리와 거의 무관하게 유지된다**:

| 임계값 | Top 5 (동명) |
|---|---|
| 1km | 구룡포읍·호미곶면·장기면·대송면·청하면 |
| 3km | 구룡포읍·호미곶면·장기면·대송면·청하면 |
| 5km | 구룡포읍·호미곶면·장기면·대송면·**송라면** |

세 임계값 모두에서 top 5에 남는 곳은 **구룡포읍·호미곶면·장기면·대송면 4곳**이다. 원인은 수학적으로 자연스럽다 — 이 네 곳은 외국인 비율 1~4위 동이고 의료 접근성은 중간 이하라, 임계거리와 무관한 수요 성분이 상위권을 붙잡아 둔다. (2026-10-09 정정: 처음엔 "의료시설 공급 자체가 희박해서"라고 썼지만, `reports/m6_validation.md`에서 접근성만 따로 보면 이 4곳이 지표에 따라 2~29위로 흩어진다는 것을 확인해 고쳤다.) 즉 **수요·접근성을 결합한 gap_score는 access_index 단독보다 "어디가 정말 시급한가"라는 질문에 더 안정적으로 답한다** — 이는 임계거리 민감도 문제(m2_two_sfca.md §7)를 없애는 것이 아니라, 우선순위 판단이 실제로 필요한 상위권에서는 영향이 상대적으로 작다는 것을 보여줄 뿐이다. 하위권 순위(예: 30위권 내 중간 순위)는 여전히 임계거리에 따라 크게 흔들리므로, 특정 동을 "몇 위"라고 단정적으로 인용하는 서술은 피해야 한다(README §7).

## 인터페이스

```
gap_scores.parquet [adm_cd, fac_type, gap_score, rank, cluster_id]
```

- `save_gap_scores()` → `data/processed/gap_scores.parquet`
- `scripts/run_pipeline.py --stage gap`로 실행 가능하도록 연결(이 커밋에서 `access`/`gap` 스테이지를 `NOT_YET_IMPLEMENTED`에서 제거).

## 2026-10-08 갱신 — 수요점 교체 후 값

수요점을 인구가중 중심점으로 바꾸면서 이 문서의 구체적 순위·점수는 바뀌었다. 상위 4곳은 구룡포읍 0.883, 장기면 0.724, 호미곶면 0.711, 대송면 0.639 순이며 네 곳 모두 1/3/5km 전부에서 5위 이내다. 5위는 죽장면(0.540). 아래 "임계거리 통합 순위" 절의 구체 사례는 기하 중심점 기준이었다. 현재는 송라면(1km 5위↔3km 19위, 변동 14)·효곡동(11)·용흥동(10)·기계면(9)이 가장 크게 흔들린다(`gap_robustness.parquet`).

## 임계거리 통합 순위와 격차 유형 (2026-10-08 추가)

`src/gap/score.py`의 `build_gap_robustness()` → `data/processed/gap_robustness.parquet`(`--stage gap`이 함께 생성). `gap_scores.parquet` 계약 컬럼은 건드리지 않고 별도 파일로 둔다.

- `1km_rank`·`3km_rank`·`5km_rank`: 임계거리별 격차 순위
- `rank_mean`·`rank_spread`: 순위 평균·(최고-최저) 차이
- `top_in_all`: 세 임계거리 모두 5위 이내인지 — 실행 결과 구룡포읍·호미곶면·장기면·대송면 4곳만 True (5위 청하면은 5km에서 6위)
- `gap_type`: 수요(외국인 비율)가 중앙값 초과인지 × 접근성이 중앙값 미만인지로 나눈 4유형(복합 취약형·수요 집중형·접근성 부족형·양호형). 29개 동 안에서의 상대 평가다.

순위 변동이 큰 동은 청림동(1km 14위↔3km 29위, 변동 15)·기계면(7)·제철동(11)이다. 이 동들은 단일 임계값 순위를 그대로 인용하면 안 된다.

## 알려진 한계

- 가중치 0.5/0.5는 검토 전 중립 기본값이다 — 위 "가중치" 절 참고.
- `cluster_id`는 실제 클러스터링이 아니라 순위 사분위 — 위 "cluster_id는..." 참고.
- 접근성 성분은 M2 바닐라 2SFCA(기본 임계값 3km) 하나에 고정 — E2SFCA(`reports/m2_e2sfca.md`)나 다른 임계값은 아직 `gap_scores.parquet`(공식 산출물)에 반영하지 않았다.
- 수요 성분(`pop_foreign_ratio`)은 M4 NLP 수요 신호(체감 결핍 유형)를 전혀 반영하지 않은 인구 통계 기반 근사치다 — "실제로 뭐가 부족하다고 느끼는가"는 아직 이 점수에 없다.

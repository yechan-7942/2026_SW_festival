# M4 — MDIS 원자료 대신 공개 결과보고서로 대체하기로 결정

작성일: 2026-09-21
작성자: Claude Code
근거: README §3 데이터 표의 "다문화가족실태조사 | MDIS | ⬜ 로그인 필요" 항목

## 배경

M4(NLP 수요 신호 추출)는 전국다문화가족실태조사 원자료(MDIS)를 입력으로 쓸 계획이었다. MDIS 계정이 뚫려서 실제 신청 절차를 확인해봤다.

## 조사 — MDIS 원격접근서비스(RAS)

이 조사(가구·개인 단위 민감정보 포함)는 **다운로드서비스가 아니라 원격접근서비스(RAS) 대상**이다. 원자료를 로컬 PC로 내려받을 수 없고, 원격분석서버 안에서만 분석 가능하며, 집계 결과표만 국가데이터처 반출승인을 받아야 가져올 수 있다.

신청 절차(8단계): 서약서·이용규정 동의 → 이용신청서(연구계획서 첨부) → 승인심사 → 이용자료 생성 → 비용결제 → RAS 이용(다운로드 불가) → 결과 반출요청 → 반출자료 검토·승인.

**비용**: 기간제 기준 1일 10,000원. 학생(대학원생·휴학생 포함) 70% 할인 적용 시 1일 3,000원. 여기에 승인까지 걸리는 기간이 불확실하고, 연구계획서 승인 여부도 확실치 않다.

## 결정: MDIS 포기, 공개 결과보고서(2차 자료)로 대체

축제 제출 일정과 비용(팀 예산 없음)을 고려해 RAS 신청을 하지 않기로 했다. 대신 여성가족부가 3년 주기로 공개하는 **전국다문화가족실태조사 결과보고서**(집계표, data.go.kr에 공개)를 2차 자료로 쓴다.

이 결정에 따른 근본적인 한계:
- 결과보고서는 **전국/광역시도 단위 집계**이지, 포항 29개 행정동 단위 분해가 아니다. 즉 행정동 간 차등화된 수요 신호를 만들 수 없다.
- 그래서 이 신호는 gap score(M3)처럼 행정동을 구분하는 정량 지표로 쓰기 어렵고, M5 정책 리포트의 LLM 프롬프트에 "포항 전체에 적용 가능한 배경 근거"로 주입하는 용도에 더 맞는다 — `src/nlp/`가 아니라 `src/policy/`에서 고정 컨텍스트로 다루는 구조가 나을 수 있다. 최종 설계는 GM 담당자와 상의 필요.

## 원본 PDF 확보 시도 — 미완료

실제 보고서 원문(항목별 애로사항 비율표 포함)을 웹에서 찾아보려 했으나, 자동화된 조회로는 확정하지 못했다.

| 시도한 링크 | 결과 |
|---|---|
| `data.go.kr/data/15048450/fileData.do` | 메타데이터 페이지뿐, 실제 파일 링크 없음 |
| `mogef.go.kr` 게시물(`bbtSn=705039`) | 첨부파일명만 노출("[용역] 2024년 전국다문화가족실태조사 연구 - 여성가족부(최윤정).pdf"), 다운로드 URL은 JS로 가려져 있어 자동 조회 불가 |
| `familynet.or.kr/download.do?uuid=...` | 다운로드는 됐지만 내용은 1페이지짜리 인포그래픽 포스터(Illustrator 제작)였음, 통계표 없음 |
| `mogef.go.kr` 보도자료(`bbtSn=712785`, "다문화자녀 고등교육 취학률 높아져") | 본문에 헤더 정보만 있고 수치 없음 |
| `kwdi.re.kr/inc/download.do?ut=A&upIdx=132494&no=1` | 다운로드는 됐지만 완전히 다른 문서(『여성연구』 2024년 3호 학술지, 다문화가족실태조사와 무관)였음 — 검색엔진이 잘못 매칭한 것으로 보임 |

**결론**: 정부 사이트들이 다운로드 링크를 JS로 감싸놔서 자동 조회로는 원문에 못 닿았다. 수치를 추측해서 MANIFEST나 리포트에 넣지 않았다 — 실제로 확인한 적 없는 값을 근거처럼 남기지 않기 위해서다.

## 남은 일

1. 팀원이 직접 브라우저로 `mogef.go.kr` 정책자료실 또는 `data.go.kr/data/15048450`에서 "결과보고서" 본문 PDF를 다운로드 (첨부파일 클릭 필요, 자동화 불가했던 부분).
2. 받은 PDF에서 항목별(의료·언어·육아·취업·자녀교육 등) 애로사항 비율표와 지역별(시도) 분해 여부 확인.
3. `data/MANIFEST.yaml`에 실제 `source_url`/`downloaded_at`/`sha256` 채워서 추가.
4. `src/policy/`(또는 `src/nlp/`) 설계는 2번 결과를 보고 확정 — 지금은 "행정동 단위가 아니다"라는 제약만 알고 실제 항목 구성은 모른다.
